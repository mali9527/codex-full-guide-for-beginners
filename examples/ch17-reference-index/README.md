# 资料目录整理的原创材料

配合[第17章](../../manuscript/goals.md)与[第18章](../../manuscript/delegation.md)。本书自行编写，所有条目均为虚构，不需另找12份真实文件。

取得[起始材料](资料目录-起始材料.zip)，把「资料目录」文件夹作为本地项目打开。材料中的4份文本是输入，结果文件夹由任务按要求新建。本例只整理登记信息，不移动或删除文件。

「演示结果」供对照内容，不放入起始材料。这些文件是本书编制并作文件级核对的示例，不是桌面Goal、分工或定时任务运行回执。输出措辞可以不同，核对标准是12个编号各一次、事实/未知保留、旧记录差异可追查。
