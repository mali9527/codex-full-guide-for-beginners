# Codex 能帮你做什么

Codex 可以帮你把一件要做的事，推进到电脑里实际可用的成果。你用日常语言说明要求，给它需要的材料，它就能在允许的范围内读取文件、处理内容、编写程序，再根据你的反馈继续修改。最后得到的可以是一份文档、一张表格，也可以是一个网页或小工具。

对没有编程经验的人来说，这意味着一些过去需要反复手工处理，或者得请别人帮忙制作的东西，现在可以自己开始做。你不必先学会一门编程语言，才有资格提出需求；可以先从熟悉的工作入手，在做的过程中逐步理解必要的操作。

## 它能接手哪些具体工作

先看几类与你可能有关的事情。下面列的是任务方向，不是已经替你完成的成果；不同材料的难度、需要的工具和可用权限，会影响实际过程。

**把零散资料整理成一份能用的文档。** 例如，你手里有几份会议记录、一些补充说明，准备写一份项目进展报告。可以让 Codex 读取这些材料，把已经完成的事、未解决的问题和下一步安排整理到一起，生成文档。第一版出来以后，再告诉它「这一段保留细节」「这部分改成给同事看的说明」，接着修改。

这类任务的价值，在于把阅读、归纳、起草和改稿连起来。你不用把每份材料里的段落逐个搬进新文件，也不用每次修改都从头整理。资料里缺了什么，它仍然需要你补充；文字写得顺，并不说明其中的事实都有依据。

**处理表格，把数字变成可以判断的信息。** 例如，几个月的采购记录分散在多张表里，同一种物品的名字又不一致。可以请 Codex 统一名称、归并记录、按月份汇总，再做一张对比图。你关心的是哪些项目花费增加了，它可以承担整理和计算中重复的部分。

这里有两种不同的需求：一种是把这次数据处理好，另一种是以后换一份数据还能重复处理。前者可能用一张整理后的表就够了，后者则可能值得做成小工具。等我们讲到表格与程序时，会沿着这个区别继续往下走。

**查找资料，比较不同来源。** 例如，准备购买一件设备，手头已经有几份产品说明，还需要查最新资料。可以把想比较的条件说清楚，请它整理规格、列出来源，并把查不到的项目留出来。这样得到的是一份帮助你选择的材料，最后的选择仍然取决于你的实际用途。

涉及最新信息时，需要用到可用的联网工具；处理电脑里的资料，则需要让它接触对应文件。你交给它的条件越明确，例如「重点比较重量和接口」，结果就越容易围绕真正的问题展开，而不是罗列一大堆你用不上的信息。

**做出自己的网页和小工具。** 网页可以用来介绍作品、展示资料，或把一份经常要查看的信息做成更方便阅读的页面。小工具则可以按你给出的规则做事，例如输入物品的数量和单价，得到购物预算；修改数量，结果随之变化。

这些变化背后要有一套电脑能够执行的指令，这就是**程序**。Codex 可以编写和修改这些指令。你负责说明这个工具给谁用、输入什么、应该得到什么结果，再用自己看得懂的例子判断它是否正确。本书会从能打开的简单网页开始，逐步加入计算，讲到怎样保存、交给别人使用，以及以后怎么改。

## 从「告诉我怎么做」到「围绕成果继续做」

假如你想整理一份报告，只问「报告应该怎么写」，得到的通常是建议；如果明确告诉它使用哪几份材料、报告给谁看、需要包含什么，并要求保存成文件，就把任务推进到了实际制作。Codex 的用法，正是在这样的来回中展开的：你提出目标，它处理材料，你看结果，再指出下一步要改哪里。

不必指望第一次就把所有要求说得完美。一份初稿常常能帮助你发现自己原先没有想清楚的地方。觉得内容太长，可以指出哪些部分缩短；发现某个数字不对，可以说明原始数据在哪里。围绕具体成果的反馈，会让后面的修改更有方向。

桌面应用支持文档、表格、演示文稿和 PDF 等文件的预览，便于一边看成果、一边继续沟通；具体格式与入口条件以应用实际支持为准。需要使用或交付时，你还要知道文件存在哪里、怎样重新打开。预览让修改方便，文件则让这次工作能够留下来。

## Codex、桌面应用和 ChatGPT 是什么关系

Codex 由 OpenAI 提供。当前官方快速开始把电脑客户端称为 **ChatGPT 桌面应用**，并在应用的 ChatGPT 下拉菜单里提供 **Codex** 入口。因此，你可能在下载和登录时看到 ChatGPT，在选好工作入口后看到 Codex。本书下一章会按这个路线带你找到它。

同一应用还提供 Chat 和 Work 等入口。它们与 Codex 的能力有重叠：官方也明确说明，可以继续用 Codex 做研究、文档、演示文稿和其他知识工作。Codex 更突出开发工具与技术细节；本书选它作为主线，是为了让你用同一条路径，从日常文件工作继续走到网页和小工具。办公任务并不是 Codex 独有的能力，也不要求你每做一种文件就换一个入口。

使用时还会看到**模型**的名字。模型承担理解要求、推理和生成内容等工作，应用则提供聊天、文件、工具等使用界面。你选择一个模型，是选择这次由哪个模型处理要求，不是另外安装一个 Codex。开始时用当前账号可用的选择即可，下一章会说明控件在哪里。

功能是否可用，还取决于平台、账号、开放进度和工作区设置。尤其是联网、外部工具以及其他扩展能力，不能只凭别人截图里有一个按钮，就认定自己的环境也已具备。我们先把当前需要的能力用起来，遇到新需求时再增加。

## 从哪里开始学，才不会一下遇到太多东西

接下来先安装应用，认识基本界面：到哪里开始工作、在哪里提出要求、从哪里看过程和成果。之后用两份零散备忘做一个小案例，得到一份待办清单。材料少，你容易看清它读了什么、改了什么；项目、聊天、保存和继续修改，也就有了具体用途。

完成这次小任务后，再把操作用到更多资料上：把要求讲清楚，整理文档和表格，接着完成之前的工作。需要反复处理同类事情时，再认识技能、插件和定时任务。网页与小工具部分会增加预览、修改、保存恢复和交付；从终端使用 Codex 的 CLI 放在后段，按需要阅读。

这条路不要求你先把所有按钮记住。先知道眼前要做什么，再学会完成这件事需要的操作，后面的功能就有地方接上了。现在从[安装应用](desktop-setup.md)开始。
