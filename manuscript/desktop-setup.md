# 第2章 安装应用，进入Codex

这一章把应用准备好：选对下载入口，完成安装和登录，进入Codex。到下一章，我们再顺着第一条消息认识界面。Windows和Mac的安装过程分开说明；登录后，两种电脑可以沿着同一条主线学习。

## 从官方入口下载

按自己的电脑选择下面的链接。直接链接无法打开时，使用同一行的官方说明页，找到当前的下载入口。

| 电脑 | 直接下载 | 官方说明 |
|---|---|---|
| Windows | [下载Windows安装程序](https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi) | [Windows应用说明](https://learn.chatgpt.com/docs/windows/windows-app) |
| 使用Apple芯片的Mac | [下载Mac安装包](https://persistent.oaistatic.com/codex-app-prod/Codex.dmg) | [桌面应用下载页](https://learn.chatgpt.com/docs/app) |

Windows链接使用Microsoft的分发服务，Mac链接指向OpenAI的安装包。下载页可能随产品更新调整，保留官方说明页，今后也容易找到对应版本。

Windows原生运行以Windows 11为推荐环境。官方对较新且完整更新的Windows 10提供尽力支持，并说明至少需要1809版本。这是支持范围，不能据此保证每台设备都能完成安装和首次设置；组织管理的电脑还可能有额外限制。

Mac下载页标注的**Apple Silicon**指Apple芯片。可以从苹果菜单进入「关于本机」，查看「芯片」一栏；使用Intel的Mac显示的是处理器信息。不要把Apple芯片安装包当成适用于所有Mac的版本。系统提示不兼容时，回官方下载页核对适用条件。

本书默认你已有可用的付费账号，沿用即可。公司或学校账号能登录，与这台电脑允许安装应用、访问文件，是不同的条件。

## Windows：安装应用，处理首次本地设置

运行取得的官方安装程序，按引导完成安装，再打开应用。桌面入门不要求先安装Git、Python或Node.js，也不需要先安装Linux环境。官方支持直接在Windows中运行。

第一次开始处理本地文件时，应用可能显示 **Set up Agent sandbox to continue**，并提供 **Set up**。这一步配置的是一层操作限制：让Codex在规定范围内接触文件和网络资源。这层限制叫**沙箱**。

如果看到提示，从Set up进入设置。官方推荐的原生沙箱设置需要管理员批准。在自己有权管理的电脑上，核对请求来自刚刚启动的应用后，再按系统提示继续。若公司设备不允许完成设置，保留错误原文，请管理员协助；账号登录成功并不能消除设备上的管理限制。

这项设置不一定紧接着安装出现，也可能在第4章开始本地任务时才出现。遇到它时按这里处理，完成后回到原任务继续。

官方提供隔离能力较弱的后备模式，但组织可能限制使用。初次设置失败，应先查[Windows沙箱说明与排障](https://learn.chatgpt.com/docs/windows/windows-sandbox)。不要把 **Full access（完全访问）**当成修复首次设置的办法。首次配置运行环境，与以后允许任务做多大范围的操作，是两件不同的事；日常权限在第7章详细讲。

## Mac：安装后打开应用

打开从官方入口取得的安装包，按其中的引导完成安装，再启动应用。系统如果提示硬件或系统版本不兼容，先核对下载条件；如果提示文件损坏，可以重新从官方入口下载，再看具体错误是否仍然出现。

安装方式以当前安装包和系统提示为准。不必为了启动桌面应用，先去安装终端工具或配置开发环境。

## 登录以后，回应用确认账号

在未登录页面选择 **Continue to sign in**，按打开的浏览器页面登录已有ChatGPT账号。浏览器如果已经登录另一个账号，先核对正在使用的是谁的账号，再继续。

桌面登录通过浏览器完成认证，再把结果交回应用。因此，浏览器显示成功后，还要回到桌面应用，确认登录页面已经消失，并从个人菜单查看当前账号。组织账号还应核对当前工作区是否符合预期。

这里的**工作区**指账号所属的使用和管理范围。例如，同一个人可能有个人使用范围，也有组织提供的范围。它和后面电脑上存放材料的文件夹不是一回事。

如果页面还提供API密钥等其他登录方式，本书继续使用ChatGPT账号。API密钥用于另一种接入方式，当前入门不需要创建它，也不需要把密码或密钥发给Codex。

## 进入Codex

登录后，在应用中的 **ChatGPT** 下拉菜单里选择 **Codex**。这一步决定现在使用哪个工作入口。上一章提到的Chat、Work和Codex有各自侧重，也有能力重叠；本书从这里开始，后面的界面与操作都沿Codex入口讲解。

用 **New chat（新聊天）** 开始一项工作。应用中的chat是围绕一件事展开的对话，本书通常称它为「任务」。按钮仍保留实际名称，方便你在界面上寻找。

现在能看到输入框、能准备发送消息，就可以进入下一章。暂时不必选择电脑文件夹；下一章先用几行文字熟悉一次最简单的交流，第4章再连接材料文件夹。

## 停在哪一步，就从那一步查

| 当前情况 | 先核对什么 |
|---|---|
| 无法下载或安装 | 使用对应平台的官方入口；核对系统、芯片和组织设备政策，保留错误原文 |
| 点击登录后没有看到页面 | 查看浏览器是否另开了登录标签；仍没有时，回应用重新发起一次登录 |
| 浏览器成功，应用仍停在登录页 | 回应用确认是否收到登录结果；若未返回，从应用重新发起登录，并核对浏览器中的账号 |
| 已登录却找不到预期入口或模型 | 核对账号与工作区，再查官方可用条件；组织账号向管理员确认访问权限 |
| Windows首次设置失败 | 查看是否缺少管理员批准或受设备政策限制，再按沙箱说明排查；不要通过放开全部权限来消除提示 |

求助时说清电脑平台、已经完成的步骤和错误原文。这样「安装程序打不开」与「已登录但没有某个模型」就不会混成同一个问题。不要在求助材料里附密码或登录凭据。

到这里，准备工作就落在三个可以确认的结果上：应用已打开，账号已确认，当前进入了Codex。下一章开始在这个界面里做一件小事。
