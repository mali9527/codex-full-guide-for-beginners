# 把桌面应用准备好：Windows 与 Mac

这一章先把 ChatGPT 桌面应用准备好，登录已有账号，找到其中的 Codex。文件材料留到下一章再接入。Windows 和 Mac 的安装入口不同，登录后的基本认识可以一起看。

## 从适合自己电脑的官方入口开始

使用 Windows，打开[官方 Windows 应用说明](https://learn.chatgpt.com/docs/windows/windows-app)，从其中的下载链接取得 Microsoft 分发的安装程序。使用 Mac，打开[官方桌面应用页](https://learn.chatgpt.com/docs/app)，选择 macOS 下载。不要把搜索结果里的第三方安装包当成本书入口。

Windows 的原生运行路线以 Windows 11 为推荐环境；官方对较新且完整更新的 Windows 10 提供尽力支持，并说明至少需要1809版本。满足版本条件仍可能遇到公司设备策略限制，不能据此保证每台电脑都能完成设置。可先在系统设置中查看自己的 Windows 版本，再判断是否适合继续。

Mac 下载入口标注 **Apple Silicon**，指使用 Apple 芯片的 Mac。可在苹果菜单的「关于本机」中查看芯片信息。如果你的电脑使用 Intel 处理器，不要把这个安装包当成适用版本；先回官方入口确认有没有与你的硬件相符的下载。系统提示版本不兼容时也先停在这里，核对下载要求，不从旧教程中拼凑安装办法。

本书沿用你已有的可用付费账号，不需要为案例另开账号。公司或学校管理的电脑还要满足该组织的安装和使用要求：账号能登录，与设备允许安装、允许访问文件，是不同条件。

## Windows：装好应用，认识首次设置

从官方链接取得 Windows 安装程序后，运行它并完成安装，再打开应用。先以能进入应用的登录界面为准；下载文件已经出现在电脑里，还不算安装完成。若安装时提示设备不兼容或组织禁止安装，记下提示，按本节末尾的排障办法处理。

Windows 可以使用原生运行方式。本书前四章不要求另装 Linux 环境，也不要求先安装 Git、Node.js 或 Python。这些工具各有用途，后面用到时再准备。

在首次开始本地工作时，应用可能出现 **Set up Agent sandbox to continue**，并提供 **Set up**。它要配置的是一层操作限制，规定 Codex 能接触哪些文件和网络资源，通常称为**沙箱**。这不是让你再安装一个模型。

出现这项提示时，从 Set up 进入设置。推荐的原生沙箱设置需要管理员批准；在自己有权管理的电脑上，核对请求确实来自刚刚启动的应用后再批准。公司电脑若不允许，不要反复换设置尝试越过限制，把错误提示交给管理员。设置成功后，回到原来的本地工作继续；若提示是在下一章打开材料时出现，就处理完再回到那一步。

官方也提供不需要同样管理员设置的后备模式，但它的隔离能力较弱，组织还可能禁止使用。初次设置失败时，先按[Windows 沙箱排障](https://learn.chatgpt.com/docs/windows/windows-sandbox)核对原因。不要为了消掉提示就选择 **Full access（完全访问）**；首次配置沙箱和放开日常操作范围是两件事。下一章会讲每次工作时怎样查看权限。

## Mac：安装后打开应用

从官方 macOS 入口下载后，打开取得的安装包，按其中的安装引导完成安装，再打开应用。常见电脑安装动作在这里不展开；我们要确认的是应用已经启动，接下来可以进行账号登录。

如果打开时提示不兼容，先核对刚才的芯片和下载版本。若提示文件损坏，重新从官方入口取得安装包；若仍然失败，保留错误原文查帮助。不要把关闭系统保护当成安装步骤，也不必为了启动桌面应用另装一套开发工具。

## 登录要回到桌面确认

在应用的未登录页面选择 **Continue to sign in**，按浏览器打开的页面登录已有 ChatGPT 账号。这里选择你平时使用这个账号的登录方式；浏览器里如果已经登录了另一个账号，先核对清楚再继续。

官方桌面登录流程通过浏览器完成认证，并把登录结果交回应用。因此，看到浏览器提示成功后，还要回到桌面应用，确认登录页已经消失，再从个人菜单核对当前账号。若账号属于组织，也要确认正在使用预期的工作区。这里的工作区指账号所属的使用与管理范围，和下一章电脑上的材料文件夹不是一回事。

页面上如果还提供其他登录方式，本书仍沿用上面的账号路线。只有当你明确准备使用 API 接入时才需要另一套凭据，本次不必为此创建密钥。

## 找到 Codex，先认这次用得到的区域

登录后，打开应用中的 **ChatGPT** 下拉菜单，选择 **Codex**。在 Codex 中进入 **New chat（新聊天）**，便来到提出新要求的位置。这里先认位置，不急着把私人文件放进去。

聊天输入框用于说明要求，聊天内容区用于看处理过程和回复。围绕电脑文件开展工作时，还要选定项目与运行位置；它们会在下一章连接「我的待办」时一并说明。先有具体文件，再解释这些选项，比在空界面里记住所有名称更容易理解。

输入框下方的模型与推理控件，用来查看和选择本次可用的模型。先保留当前可用选择，不必照着别人的截图寻找同一个型号。如果控件里没有某个名字，换一个拼写或反复点击不会给账号增加权限，应先核对当前账号和工作区条件。

现在可以做一次准备检查：应用已登录，个人菜单显示的是预期账号，可以进入 Codex 的新聊天页面并看到可用的模型选项。这说明可以继续准备文件；是否能在选定文件夹里实际读写，要到后两章用材料和结果来确认。

## 卡住时，先看是哪一段没有完成

安装失败、登录失败和额度不足，后续处理不同。先保留具体提示，比一句「用不了」更容易定位。

| 看到的情况 | 下一步 |
|---|---|
| 下载或安装提示不兼容 | 回对应平台的官方入口，核对硬件、系统版本与下载项；组织电脑同时确认安装政策 |
| 点了登录，却没有看到浏览器页面 | 查看常用浏览器是否另开了登录标签；回应用重新发起登录，并保留仍出现的错误提示 |
| 浏览器已经完成，应用还停在登录页 | 回到应用等待返回；若仍没有变化，重新从应用发起一次登录，核对浏览器用的是同一账号，不把网页登录状态当成桌面已登录 |
| 已登录，却没有可用的 Codex 入口或模型 | 先查个人菜单中的账号与工作区，再查官方的功能可用条件；组织账号向管理员确认访问权限 |
| Windows 提示沙箱设置失败 | 核对是否拒绝了管理员请求；受管理设备把原始报错交给管理员，并查本章链接的沙箱排障，不改成完全访问来绕过。若报错明确提示缺少 winget（Windows 用来获取和管理软件的工具），按该页要求更新 Windows 或补齐程序包管理器；受管理设备请管理员处理 |
| 提示达到使用额度 | 从[官方额度说明](https://learn.chatgpt.com/docs/pricing#where-can-i-see-my-current-usage-limits)中的 usage dashboard 查看个人当前额度与重置时间；重装应用不能作为处理额度问题的办法 |

排障求助时，说明用的是 Windows 还是 Mac、应用是否已经打开、停在哪一步，并附错误原文。不要发送密码、登录凭据或无关的私人文件。应用准备好后，进入下一章，把本书的两份备忘放到一个明确的文件夹里。
