# 安装应用，认识 Codex 的基本界面

开始使用 Codex，先安装桌面应用，登录已有账号，再进入 Codex。安装以后，我们会顺着一次工作的过程认识界面：在哪里找到任务，在哪里提出要求，处理过程和结果又到哪里看。Windows 和 Mac 分开安装，之后的基本用法可以一起理解。

## 从适合自己电脑的官方入口开始

下面是官方提供的下载链接，按自己的电脑选择。

| 电脑 | 下载链接 | 官方说明与备用入口 |
|---|---|---|
| Windows | [下载 Windows 安装程序](https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi) | [Windows 应用说明](https://learn.chatgpt.com/docs/windows/windows-app) |
| 使用 Apple 芯片的 Mac | [下载 Mac 安装包](https://persistent.oaistatic.com/codex-app-prod/Codex.dmg) | [桌面应用官方下载页](https://learn.chatgpt.com/docs/app) |

Windows 链接使用 Microsoft 的分发服务，Mac 链接指向 OpenAI 的安装包。若直接链接打不开，回到同一行的官方页面，使用其中当前的下载入口。

Windows 的原生运行路线以 Windows 11 为推荐环境；官方对较新且完整更新的 Windows 10 提供尽力支持，并说明至少需要1809版本。满足版本条件仍可能遇到公司设备策略限制，不能据此保证每台电脑都能完成设置。可先在系统设置中查看自己的 Windows 版本，再判断是否适合继续。

Mac 下载入口标注 **Apple Silicon**，指使用 Apple 芯片的 Mac。可在苹果菜单的「关于本机」中查看芯片信息。如果你的电脑使用 Intel 处理器，不要把这个安装包当成适用版本；先回官方入口确认有没有与你的硬件相符的下载。系统提示版本不兼容时也先停在这里，核对下载要求，不从旧教程中拼凑安装办法。

本书沿用你已有的可用付费账号，不需要为案例另开账号。公司或学校管理的电脑还要满足该组织的安装和使用要求：账号能登录，与设备允许安装、允许访问文件，是不同条件。

## Windows：装好应用，认识首次设置

从官方链接取得 Windows 安装程序后，运行它并完成安装，再打开应用。打开后应进入应用的登录流程。若提示设备不兼容或组织禁止安装，保留提示，按本章末尾的排障办法处理。

Windows 可以使用原生运行方式。本书前四章不要求另装 Linux 环境，也不要求先安装 Git、Node.js 或 Python。这些工具各有用途，后面用到时再准备。

在首次开始本地工作时，应用可能出现 **Set up Agent sandbox to continue**，并提供 **Set up**。它要配置的是一层操作限制，规定 Codex 能接触哪些文件和网络资源，通常称为**沙箱**。这不是让你再安装一个模型。

出现这项提示时，从 Set up 进入设置。推荐的原生沙箱设置需要管理员批准；在自己有权管理的电脑上，核对请求确实来自刚刚启动的应用后再批准。公司电脑若不允许，不要反复换设置尝试越过限制，把错误提示交给管理员。设置成功后，回到原来的本地工作继续；若提示是在下一章打开材料时出现，就处理完再回到那一步。

官方也提供不需要同样管理员设置的后备模式，但它的隔离能力较弱，组织还可能禁止使用。初次设置失败时，先按[Windows 沙箱排障](https://learn.chatgpt.com/docs/windows/windows-sandbox)核对原因。不要为了消掉提示就选择 **Full access（完全访问）**；首次配置沙箱和放开日常操作范围是两件事。下一章会讲每次工作时怎样查看权限。

## Mac：安装后打开应用

从官方 macOS 入口下载后，打开取得的安装包，按其中的引导完成安装，再从应用程序中启动它，进入登录流程。

如果打开时提示不兼容，先核对刚才的芯片和下载版本。若提示文件损坏，重新从官方入口取得安装包；若仍然失败，保留错误原文查帮助。不要把关闭系统保护当成安装步骤，也不必为了启动桌面应用另装一套开发工具。

## 登录要回到桌面确认

在应用的未登录页面选择 **Continue to sign in**，按浏览器打开的页面登录已有 ChatGPT 账号。这里选择你平时使用这个账号的登录方式；浏览器里如果已经登录了另一个账号，先核对清楚再继续。

官方桌面登录流程通过浏览器完成认证，并把登录结果交回应用。因此，看到浏览器提示成功后，还要回到桌面应用，确认登录页已经消失，再从个人菜单核对当前账号。若账号属于组织，也要确认正在使用预期的工作区。这里的工作区指账号所属的使用与管理范围，和下一章电脑上的材料文件夹不是一回事。

页面上如果还提供其他登录方式，本书仍沿用上面的账号路线。只有当你明确准备使用 API 接入时才需要另一套凭据，本次不必为此创建密钥。

## 进入 Codex，看懂界面里的分工

登录后，打开应用中的 **ChatGPT** 下拉菜单，选择 **Codex**。用 **New chat（新聊天）** 开始一项工作。你会看到用于交流的聊天区域和输入框；随着文件与任务加入，项目和成果也会出现在各自的位置。窗口大小、应用版本和当前视图会影响布局，先认识这些区域的用途。

### 项目和聊天：把不同的工作放清楚

侧栏用于回到项目和已有聊天。**项目**把相关的工作组织在一起；需要处理电脑文件时，可以把相应文件夹连接成**本地项目**。例如，我们稍后会有一个「我的待办」文件夹，原始备忘和整理后的清单都放在里面。

**聊天**是围绕一件事来回交流的地方。第一次请 Codex 整理清单，开始一个聊天；发现这份清单需要补充，就在原聊天里接着说。以后要写一份无关的报告，可以另开聊天。项目让相关工作容易找到，聊天让每件事的要求、进展与修改不至于混在一起。

现在先知道两者的区别。下一章会实际选择文件夹，并检查新聊天是否在正确的项目中。

### 输入框和聊天内容：提出要求，看它怎样处理

你把要求写进输入框并发送，Codex 就根据这次任务可用的材料与工具开始处理。聊天内容区用于查看回复和工作进展。做文件任务时，里面可能出现读取、修改等操作信息，也可能出现向你补问的问题，或等待批准的请求。

看这些信息，是为了知道工作进行到哪里。如果它在等你补充材料，继续等待不会让材料自己出现；如果它已经给出结果，你就可以查看成果，再在同一个输入框提出修改意见。交流不必每次重新开头，也不用把一句普通要求写成特殊命令。

### 输入框附近的选项：决定怎样开展这次工作

模型、工作位置和权限解决的是不同问题，不能互相替代。

| 选项 | 用来做什么 | 刚开始怎么用 |
|---|---|---|
| 模型与推理设置 | 选择处理要求的模型及其思考投入；更高的推理投入可能适合复杂问题，也会花更长时间 | 先用当前可用选择，不为一个简单文件任务反复换型号 |
| 项目与运行位置 | 指定围绕哪份工作、在哪里处理文件 | 下一章连接「我的待办」，再选择 Local，使用电脑里的材料 |
| 权限 | 决定允许哪些操作，以及什么时候需要批准 | 下一章选择 Ask for approval，并结合实际读写说明其范围 |

模型与权限控件位于输入框下方。换模型不会自动扩大文件访问权限；要求「只看不改」，也不会自动改变权限设置。先认清它们各管什么，具体设置等材料到位后再做。

### 成果预览：边看文件，边提修改意见

对于应用支持的文档、表格、演示文稿、PDF 等文件，桌面应用可以在聊天旁边显示预览。聊天里说的是它做了什么，预览里看的是成果本身。以后修改报告，你可以一边看报告内容，一边说明哪一段需要调整；支持批注的预览还可以针对具体位置提出意见。

并非所有文件都会自动打开预览，自动打开也受设置影响。找不到预览时，仍可到保存位置用合适的软件打开文件。我们第一次做的是简单文本清单，会直接到文件夹查看；学到文档和网页时，再使用相应预览。

你可能还会看到更多工具或开发相关入口。它们会随任务逐步用到：文件处理先学项目与聊天，做网页时再看浏览器中的页面，重复工作时再安排技能或定时任务。不必在安装后先配置一遍所有选项。

## 卡住时，先看是哪一段没有完成

安装失败、登录失败和额度不足，后续处理不同。先保留具体提示，比一句「用不了」更容易定位。

| 看到的情况 | 下一步 |
|---|---|
| 下载或安装提示不兼容 | 回对应平台的官方入口，核对硬件、系统版本与下载项；组织电脑同时确认安装政策 |
| 点了登录，却没有看到浏览器页面 | 查看常用浏览器是否另开了登录标签；回应用重新发起登录，并保留仍出现的错误提示 |
| 浏览器已经完成，应用还停在登录页 | 回到应用等待返回；若仍没有变化，重新从应用发起一次登录，核对浏览器用的是同一账号，不把网页登录状态当成桌面已登录 |
| 已登录，却没有可用的 Codex 入口或模型 | 先查个人菜单中的账号与工作区，再查官方的功能可用条件；组织账号向管理员确认访问权限 |
| Windows 提示沙箱设置失败 | 核对是否拒绝了管理员请求；受管理设备把原始报错交给管理员，并查本章链接的沙箱排障，不改成完全访问来绕过。若报错明确提示缺少 winget（Windows 用来获取和管理软件的工具），按该页要求更新 Windows 或补齐程序包管理器；受管理设备请管理员处理 |
| 提示达到使用额度 | 从[官方额度说明](https://learn.chatgpt.com/docs/pricing#where-can-i-see-my-current-usage-limits)中的 usage dashboard 查看个人当前额度与重置时间；重装应用不能作为处理额度问题的办法 |

排障求助时，说明用的是 Windows 还是 Mac、应用是否已经打开、停在哪一步，并附错误原文。不要发送密码、登录凭据或无关的私人文件。应用准备好后，进入下一章，把本书的两份备忘放到一个明确的文件夹里。
