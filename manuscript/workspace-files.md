# 把文件准备好，让 Codex 找到它

平时请人帮忙整理东西，我们会先把东西交到他手里。让 Codex 整理电脑里的文件，也要先说明它们放在哪里。你在电脑上能看见一份备忘，不代表眼前这次聊天已经知道去哪里找它。

这一章先做这件准备工作：把两份短备忘放进一个文件夹，再让 Codex 找到它们、说说里面记了什么。等两边看到的是同一份内容，下一章就可以请它整理清单了。这里从已经安装并登录的 ChatGPT 桌面应用开始，使用其中的 Codex 入口。

## 先拿到两份备忘

打开[配套材料页](../examples/ch04-notes-to-todos/README.md)，保存「我的待办-起始材料.zip」。这是本书自编的演示材料，记录了发照片、买笔记本等几件小事。先用这份材料一起走一遍，不需要拿自己的私人文件来试。

文件名末尾的 `.zip` 表示它是一个**压缩包**，几份文件装在一起，传递起来方便。把它解压，就能拿到里面的普通文件夹。下载时如果浏览器让你选位置，选一个容易找到的地方；已经下载却不知道在哪里，可以打开浏览器的下载列表，用文件旁的按钮找到它在电脑里的位置。

<!-- 编辑待验证 PREP-01：配套材料尚无发行地址；发行前补稳定下载入口及Windows/Mac真实下载界面。当前链接可本地查看，不能称已验证公开下载路径。 -->

接着在电脑里找到这个压缩包。Windows 上用**文件资源管理器（File Explorer）**，Mac 上用**访达（Finder）**，它们就是平时查看文件和文件夹的地方。

- **Windows**：在压缩包上点右键，使用解压全部文件的选项，在随后出现的窗口里确认保存位置。微软支持页把这个选项称为「全部提取」。
- **Mac**：双击压缩包即可解压。Safari 可能已经在下载后完成了解压；如果你拿到的已经是普通文件夹，就从那里继续。

<!-- 编辑待验证 PREP-02：Windows实际菜单译名、解压窗口与两平台生成层级未实测。上述动作依据厂商文档，不将支持页译名当成已核对的界面文案。 -->

解压后，找到名叫「我的待办」的文件夹，把它放在你容易找到的位置，例如桌面。有时外面还有一层以压缩包命名的文件夹，往里打开就能找到。判断自己选对了哪一层，有个直接的办法：「我的待办」里面有一个「材料」文件夹，再往里是「随手记.txt」和「补充说明.txt」。

打开「随手记」看一眼。Windows 可以用**记事本（Notepad）**，Mac 可以用**文本编辑（TextEdit）**。第一行是本书的演示说明，后面才是备忘：发照片记了两遍，整理书桌还没有定日期。再打开「补充说明」，你会看到照片要选10张，笔记本要横线款。下一章要做的，就是把这些分散的信息放回同一份清单里。

文件名末尾的 `.txt` 叫**扩展名**，用来标明文件类型。这里是纯文本文件：保存的是文字，文字本身不附带字体和颜色等排版设置。有的电脑会隐藏扩展名，只显示「随手记」，不影响使用，不用自己再补一遍。

## 把这个文件夹连接进来

回到 ChatGPT 桌面应用，在 ChatGPT 下拉菜单中选择 **Codex**。我们接下来要连接的，是刚才准备好的「我的待办」文件夹。

在 Codex 界面，Windows按 **Ctrl+O**，也就是按住Ctrl键，再按字母O；Mac按 **⌘O**，也就是按住Command键，再按字母O。这是官方列出的「打开文件夹（Open folder）」默认快捷键。在打开的选择窗口中找到「我的待办」，选中并打开它。

<!-- 编辑待验证 PREP-03：快捷键及适用桌面入口已由官方Commands文档确认；选择器外观、选完后的界面状态及自定义快捷键恢复路径待Mac/Windows实测和截图。不得补猜按钮坐标。 -->

这一步把电脑里的文件夹接到了项目上。连接着电脑文件夹、用来组织相关聊天的项目，叫**本地项目**。以后回到这个项目，就有一个明确的地方继续处理这些备忘。文件夹在哪里，比项目名字起得是否好看更重要。

接着在这个项目里开始一个**新聊天（New chat）**，也就是从这里开始的一段对话。Windows可以按Ctrl+N，Mac可以按⌘N；这两个也是默认快捷键。把运行位置选为 **Local（本地）**。这里的「本地」表示在电脑上的项目文件夹里工作。接下来读备忘、整理清单、修改清单，都留在这次聊天里，方便接着前面的要求往下做。

## 先看清它能做什么

文件夹连接好了，还要看一眼它可以做哪些操作。这些安排叫**权限**。本书在这一段使用 **Ask for approval（请求批准）**：按官方说明，它可以在当前允许的范围内读写文件、执行常规本地操作；需要额外访问时再请求批准。具体范围受设置影响，不能只凭项目的名字判断。

开始前确认当前聊天使用的是这一档。官方把权限选择放在输入框下方；如果你此前调整过设置，或使用组织管理的账号，实际选项可能不同。我们要用的是能整理演示文件、又能在需要额外权限时停下来询问的工作方式。

<!-- 编辑待验证 PREP-05：权限控件的文档位置已确认；本账号初始状态、中文标签和真实弹窗尚未验证。 -->

遇到请求时，先看它要做什么、访问哪里，再决定是否允许。比如这次只需要看两份备忘，整理清单还没有开始。看不明白就先拒绝，请它解释，不用为了继续往下做而猜。使用自己的材料时，也先确认其中没有不宜交给 AI 服务处理的信息。

## 让它说说自己找到了什么

现在可以发第一句话了。在聊天输入框里写下下面这段要求，再用发送按钮发出去：

> 看一下「材料」里有哪些文件，各自记了什么。先不要改文件。

这样发给 Codex 的要求，也叫**提示词**。不用先记专门的句式，把眼前要做的事情说清楚就可以。这里先请它看一遍，是为了确认文件夹接对了，免得整理完才发现处理的是另一份东西。

等它给出内容说明，再和你刚才打开的备忘对一对。它应当找到「随手记」和「补充说明」，知道里面有发照片、整理书桌、买笔记本、联系维修店这几件事，也能看到照片数量和笔记本样式的补充要求。只有文件名对上还不够，内容也要能对应。

我们发的是「先不要改文件」，此时还不需要出现新清单。也回到两份原备忘再看一眼，确认仍是刚才那些内容。两份备忘都找到了，内容也一致，就留在这个聊天里，接着读下一章。

## 没得到预期结果时

| 停在了哪里 | 可以先做什么 |
|---|---|
| 下载后找不到文件 | 回到浏览器下载列表，使用显示文件位置的入口；若下载没有完成，先等它完成 |
| 解压后文件夹层级对不上 | 找到里面直接有「材料」的「我的待办」，不要只按最外层文件夹的名字判断 |
| 双击备忘打开了别的软件 | 在文件上点右键，通过「打开方式」选择记事本或文本编辑 |
| 备忘打开后是乱码 | 先关闭，不要覆盖保存；使用支持UTF-8的文本打开方式。UTF-8是一种保存多种文字的编码方式，不确定设置时保留原件再处理 |
| 快捷键没有打开选择窗口 | 先确认当前使用Codex入口，并检查是否改过快捷键；官方命令名称为Open folder |
| Codex找不到两份备忘 | 核对连接的是「我的待办」，请它列出看到的文件名；已经建立的项目可在Edit project（编辑项目）中通过Add folder（添加文件夹）核对连接 |
| Windows提示尚未完成初始设置 | 先按应用引导完成首次环境设置，再回来打开文件夹；具体页面按第2章的安装路径核对 |
