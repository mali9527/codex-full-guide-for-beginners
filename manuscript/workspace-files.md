# 把文件准备好，让 Codex 找到它

发照片的提醒记了两遍，买笔记本的要求又补在另一份备忘里。我们接下来要请 Codex 把这些零散信息整理成清单。开始之前，先让它找到材料，确认两边看到的是同样的内容。

这一章从已经安装并登录的 ChatGPT 桌面应用开始，使用其中的 Codex 入口。先准备两份短备忘，请它读一遍，下一章再整理和保存。

## 先拿到两份备忘

打开[配套材料页](../examples/ch04-notes-to-todos/README.md)，保存「我的待办-起始材料.zip」。这是本书自编的演示材料，不含真实个人信息。

`.zip` 表示它是一个**压缩包**，把几份文件装在一起，方便下载。**解压**后，我们就能使用里面的普通文件夹。下载时选一个容易找到的位置；已经下载却找不到，可以从浏览器的下载列表查看文件位置。

<!-- 编辑待验证 PREP-01：配套材料尚无发行地址；发行前补稳定下载入口及Windows/Mac真实下载界面。当前链接可本地查看，不能称已验证公开下载路径。 -->

在电脑里找到这个包。Windows 用**文件资源管理器（File Explorer）**，Mac 用**访达（Finder）**，它们都是平时查看文件和文件夹的地方。

- **Windows**：在压缩包上点右键，使用解压全部文件的选项，在随后出现的窗口中确认保存位置。微软支持页称这个选项为「全部提取」。
- **Mac**：双击压缩包解压。Safari 可能已经自动解压；拿到普通文件夹后，就可以继续。

<!-- 编辑待验证 PREP-02：Windows实际菜单译名、解压窗口与两平台生成层级未实测。上述动作依据厂商文档，不将支持页译名当成已核对的界面文案。 -->

找到解压出来的「我的待办」，把它放在容易找到的位置，例如桌面。如果外面还有一层以压缩包命名的文件夹，继续往里找。我们要用的是这一层：

| 文件夹 | 里面放什么 |
|---|---|
| 我的待办 | 「材料」文件夹；下一章还会新增「结果」文件夹 |
| 材料 | 「随手记.txt」和「补充说明.txt」两份原件 |
| 结果 | 整理后的清单；现在还没有这个文件夹 |

原件和结果分开放，发现疑问时才有依据可查。起始压缩包也先留着，需要时可以重新解压出一份原材料。

## 打开看看，认识我们要整理的内容

打开「材料」里的「随手记」。Windows 可以用**记事本（Notepad）**，Mac 可以用**文本编辑（TextEdit）**。

第一行是演示说明，后面记了发照片、整理书桌、买笔记本、联系维修店四件事。再打开「补充说明」，你会看到照片要选10张、笔记本要横线款，以及日期和预约尚未确定的说明。前一份记事情，后一份补要求，整理时两份都要看。

文件名末尾的 `.txt` 叫**扩展名**，这里表示**纯文本文件**：保存文字，不附带字体和颜色等排版设置。有的电脑会隐藏扩展名，只显示「随手记」，不用再给它补一遍 `.txt`。现在先看内容，不改原件。

## 把文件夹连接到 Codex

回到 ChatGPT 桌面应用，在 ChatGPT 下拉菜单中选择 **Codex**。接下来连接外层的「我的待办」：我们既要读取里面的「材料」，又要在旁边建立「结果」，所以选它们共同的外层文件夹。

用下面的**快捷键**，也就是组合按键，打开「打开文件夹（Open folder）」窗口：

- **Windows**：按住 Ctrl，再按字母 O，即 **Ctrl+O**。
- **Mac**：按住 Command，再按字母 O，即 **⌘O**。

这些是默认快捷键。在出现的选择窗口中找到「我的待办」，选中并打开它；不要选压缩包或单独一份备忘。

<!-- 编辑待验证 PREP-03：快捷键及适用桌面入口已由官方Commands文档确认；选择器外观、选完后的界面状态及自定义快捷键恢复路径待Mac/Windows实测和截图。不得补猜按钮坐标。 -->

这样连接电脑文件夹、组织相关聊天的项目，叫**本地项目**。文件夹存放材料和成果，项目把围绕它们开展的工作组织起来。

接着在这个项目里开始**新聊天（New chat）**。Windows 可以按 Ctrl+N，Mac 可以按 ⌘N。把运行位置选为 **Local（本地）**，表示直接在电脑上的当前项目文件夹中工作。这两章处理的是同一份清单，先在这次聊天里继续读材料、提要求和修改。

## 先看清它能做什么

**权限**决定 Codex 可以做哪些操作，以及何时需要批准。在输入框下方确认当前聊天使用 **Ask for approval（请求批准）**。按官方说明，这一档允许它在当前范围内读写文件、执行常规本地操作，需要额外访问时再询问。具体范围和可选模式受设置及组织要求影响。

这个名字并不表示每读一次文件、每改一行字都会再问。遇到请求时，看清它要做什么、访问哪里；看不明白先拒绝，再请它解释。使用自己的材料前，也确认其中没有不宜交给 AI 服务处理的信息。

## 让它读一遍，确认材料找对了

在聊天输入框里写下这段要求，用发送按钮发出去：

> 看一下「材料」里有哪些文件，各自记了什么。先不要改文件。

发给 Codex 的要求叫**提示词**。这里说明了去哪里看、看完告诉你什么，以及暂时不要改动。最后一句是工作要求，不会自动把权限切换成只能读取，原件仍要检查。

回复里只有「找到了两个文件」还不够。看看它能否说出照片选10张、笔记本要横线款这些细节。文件名和内容都能对应，才有理由继续；对不上，就指出具体差异，请它重新读取。

这也是处理陌生材料时值得保留的习惯：先确认理解，再开始加工。以后资料多了，挑几条关键事实核对，能帮助你尽早发现读错文件或漏读材料的问题，不必等整份结果做完才回头找原因。

最后关闭先前查看备忘的窗口，再从「材料」里打开两份原件，确认内容没变。此时还没有要求生成清单，不需要出现「结果」文件夹。确认好以后，留在这个聊天里进入下一章。

## 没得到预期结果时

| 停在了哪里 | 可以先做什么 |
|---|---|
| 下载后找不到文件 | 从浏览器下载列表查看文件位置；若下载未完成，先等它完成 |
| 解压后层级对不上 | 找到里面直接有「材料」的「我的待办」 |
| 双击备忘打开了别的软件 | 在文件上点右键，通过「打开方式」选择记事本或文本编辑 |
| 备忘打开后是乱码 | 先关闭，不要覆盖保存；使用支持UTF-8的文本打开方式。UTF-8是一种保存多种文字的编码方式，不确定设置时保留原件再处理 |
| 快捷键没有反应 | 确认当前使用Codex入口，并检查是否改过快捷键；命令名称为Open folder |
| Codex找不到备忘 | 核对连接位置，请它列出文件名；已有项目可在Edit project（编辑项目）中通过Add folder（添加文件夹）核对连接 |
| Windows提示需要初始设置 | 先按应用引导完成设置，具体路径见第2章，再回来继续 |
| 只是查看，关闭时却询问保存 | 先取消关闭，检查是否不小心改了文字；确认无需保留这些改动后，再关闭而不保存 |
