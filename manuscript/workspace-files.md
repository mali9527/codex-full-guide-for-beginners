# 把文件准备好，让 Codex 找到它

有些事情，我们并不是忘了做，而是记在了不同的地方。出游回来，要给朋友发照片，随手记了一次，过两天又提醒自己一次；要买一本笔记本，先记下「买新的」，后来才想起补一句「要横线款」。等到真正准备处理时，还得把这些零散的信息重新理一遍。

这正是我们接下来要交给 Codex 的事。不过，先别急着让它整理。你能在电脑上找到一份备忘，眼前这次聊天却未必知道它在哪里。先把材料放好，再让它找到同样的内容，后面的交流就有了共同的依据。

这一章从已经安装并登录的 ChatGPT 桌面应用开始，使用其中的 Codex 入口。我们先准备两份短备忘，请它读一读；下一章再把备忘整理成一份可以保存、继续修改的清单。材料里的每件事都很日常，读完原文，你自己就能判断它有没有理解对。

## 先拿到两份备忘

打开[配套材料页](../examples/ch04-notes-to-todos/README.md)，保存「我的待办-起始材料.zip」。这是本书自编的演示材料，里面没有真实个人信息。先用同一份材料走一遍，书中提到的文件名和具体内容就都能对上。

文件名末尾的 `.zip` 表示它是一个**压缩包**。你可以把它理解为打包在一起的一组文件：下载时拿到一个包，**解压**之后，才能按普通文件夹的方式使用里面的材料。我们之后交给 Codex 的是解压出来的文件夹。

下载时，如果浏览器让你选保存位置，选一个容易找到的地方。已经下载却不知道放在哪里，可以打开浏览器的下载列表，用文件旁显示位置的入口找到它。下载位置可以更改，所以不用认定它一定在某个固定文件夹里。

<!-- 编辑待验证 PREP-01：配套材料尚无发行地址；发行前补稳定下载入口及Windows/Mac真实下载界面。当前链接可本地查看，不能称已验证公开下载路径。 -->

接着找到这个压缩包。Windows 上用**文件资源管理器（File Explorer）**，Mac 上用**访达（Finder）**，它们就是平时查看文件和文件夹的地方。

- **Windows**：在压缩包上点右键，使用解压全部文件的选项，在随后出现的窗口里确认保存位置。微软支持页把这个选项称为「全部提取」。
- **Mac**：双击压缩包即可解压。Safari 可能已经在下载后完成了解压；如果拿到的已经是普通文件夹，就从那里继续。

<!-- 编辑待验证 PREP-02：Windows实际菜单译名、解压窗口与两平台生成层级未实测。上述动作依据厂商文档，不将支持页译名当成已核对的界面文案。 -->

解压后，找到名叫「我的待办」的文件夹，把它放在你容易找到的位置，例如桌面。有时外面还会有一层以压缩包命名的文件夹，往里打开即可。选对的那一层，里面直接有一个「材料」文件夹；再打开「材料」，就能看到「随手记.txt」和「补充说明.txt」。

这几个名字各有用处：

| 位置 | 用来放什么 | 现在应该看到什么 |
|---|---|---|
| 我的待办 | 这次事情用到的全部文件 | 里面有「材料」文件夹 |
| 我的待办里的「材料」 | 两份尚未整理的备忘，也就是原件 | 「随手记.txt」和「补充说明.txt」 |
| 以后新增的「结果」 | 整理后的清单 | 下一章才创建，现在没有是正常的 |

把原件和结果分开放，以后发现清单里某句话不对，还能回头找到它原来怎么写。起始压缩包也先留着；需要重新拿一份原材料时，可以从里面再解压一份。

## 打开看看，认识我们要整理的内容

先打开「随手记」。Windows 可以用**记事本（Notepad）**，Mac 可以用**文本编辑（TextEdit）**。它们都能查看这里的文字。如果双击后打开了别的软件，可以在文件上点右键，通过「打开方式」选择对应的文本应用。

第一行是本书的演示说明，后面才是备忘。你会看到发照片、整理书桌、买笔记本、联系维修店这几件事。其中，发照片记了两遍；整理书桌只说要做，日期还没有想好。

再打开「补充说明」。里面没有重新列一份待办，而是补上了几件事的要求，例如：

> 给朋友发照片，选10张就好，不用发整个相册。
>
> 新买的纸质笔记本要横线款。

这两份文件各自都读得懂，合在一起才是完整的意思。「随手记」告诉我们要做什么，「补充说明」又告诉我们怎样做、哪些事情还没有确定。下一章整理时，如果只看前一份，照片数量和笔记本样式就会漏掉。

文件名末尾的 `.txt` 叫**扩展名**，用来标明文件类型。这里用的是**纯文本文件**：它保存文字，文字本身不附带字体、颜色等排版设置。我们先用这种格式，是为了把注意力放在内容上——事项有没有漏，日期有没有变，补充要求有没有跟过来。

有的电脑会隐藏扩展名，只显示「随手记」或「补充说明」，不影响使用，也不用自己再补一遍 `.txt`。文件名主要用来帮助我们辨认文件；真正要处理的内容，要打开文件才能看到。现在只看一遍，先不改动这两份备忘。

## 为什么要把整个「我的待办」连接进来

回到 ChatGPT 桌面应用，在 ChatGPT 下拉菜单中选择 **Codex**。接下来要选的是外层的「我的待办」文件夹。

这里选外层，是因为我们要在同一个地方做两件事：读「材料」里的备忘，再在「材料」旁边建立一个「结果」文件夹。把共同的外层文件夹交代清楚，接下来谈到「材料」和「结果」，双方就知道它们属于哪一次工作。

在 Codex 界面，Windows 按 **Ctrl+O**，也就是按住 Ctrl 键，再按字母 O；Mac 按 **⌘O**，也就是按住 Command 键，再按字母 O。按键写法里的加号表示组合使用，不是还要按一次加号键。这种用一组按键完成指定操作的方式，叫**快捷键**。这里对应的是「打开文件夹（Open folder）」，按法采用官方默认设置。

在打开的选择窗口中找到「我的待办」，选中并打开它。我们要连接的是这个文件夹，不是压缩包，也不是里面某一份 `.txt` 文件。

这一步会遇到一个新词：**本地项目**。在这里，项目是应用中组织这件工作的地方，它连接着电脑里的文件夹，也用来组织相关聊天。电脑文件夹负责存放文件，项目则让我们能围绕这些文件继续工作。以后看到「项目」，不必先想到一个很大的软件工程；整理这两份备忘，也可以使用项目。

## 从这个项目开始聊天

接着，在这个项目里开始一个**新聊天（New chat）**。聊天就是你提出要求、Codex 回应、你再接着补充的一段对话。项目管着相关工作，聊天则承载这一次具体的交流。

Windows 可以按 Ctrl+N，Mac 可以按 ⌘N；按法和刚才一样，只是把字母 O 换成 N。这两个也是默认快捷键。把运行位置选为 **Local（本地）**，表示这次直接在电脑上的当前项目文件夹里工作。

对眼前的例子来说，文件夹是「我的待办」，接下来要读的是里面的两份备忘；聊天输入框里写的，则是你希望怎样处理它们。先分清这两处，后面看到它在聊天里说「整理好了」，就会自然想到回文件夹里看实际留下了什么。

<!-- 编辑待验证 PREP-04：新聊天入口和Local选项来自官方文档；具体位置、初始选中值和本轮界面中文文案待实测，不能声称默认已选或语言包名称已在屏幕出现。 -->

这两章会沿着同一件事往下做，所以先留在这次聊天里。读备忘、整理清单、修改清单，都在这里接着说，免得每做一步就重新寻找前面的要求。

## 先看清它能做什么

文件夹连接好了，还要看一眼它可以做哪些操作。这些安排叫**权限**。本书在这一段使用 **Ask for approval（请求批准）**：按官方说明，它可以在当前允许的范围内读写文件、执行常规本地操作；需要额外访问时再请求批准。具体范围受设置影响，不能只凭项目的名字判断。

开始前确认当前聊天使用的是这一档。官方把权限选择放在输入框下方；如果你此前调整过设置，或使用组织管理的账号，实际选项可能不同。

<!-- 编辑待验证 PREP-05：权限控件的文档位置已确认；本账号初始状态、中文标签和真实弹窗尚未验证。 -->

「请求批准」这个名字容易让人以为，每读一次文件、每改一行字，它都会再问一次。实际并不是这样：在已经允许的范围内，它可以继续操作。我们仍然需要在要求里说清楚这次打算做什么，并检查结果。

遇到请求时，先看它要做的事情和准备访问的位置。例如现在只是看两份备忘，生成清单还没开始。如果它要做的事情超出了你理解的范围，先拒绝，请它解释原因。使用自己的材料时，也先确认其中没有不宜交给 AI 服务处理的信息。

## 让它说说自己找到了什么

现在可以发第一句话了。在聊天输入框里写下下面这段要求，再用发送按钮发出去：

> 看一下「材料」里有哪些文件，各自记了什么。先不要改文件。

这样发给 Codex 的要求，也叫**提示词**。它不必是一大段专业指令。这句话已经说明了去哪里看、看完要告诉你什么，以及这一次先不做什么。

这里的「先不要改文件」是我们交代的工作要求，不会把权限设置自动切换成只能读取。权限决定它可以做哪些操作，提示词说明我们此刻希望它做哪一件事。因此，即使要求只是看一遍，后面也要核对原件有没有变化。

等它给出内容说明，再和你刚才打开的备忘对一对。假如回复只说「找到了两个文本文件」，你还不知道它是否读到了里面的具体要求。再往下看看，它能不能说出照片要选10张、笔记本要横线款，以及书桌日期尚未确定。

这些细节的作用，是帮助我们判断两边看的是否同一份内容。回复的句子不必和书上一模一样；说「只选10张照片」和说「照片数量是10张」，意思能对应就可以。需要留意的是数量、事项、要求和未确定的状态。

如果内容对不上，可以先告诉它哪里不同。例如：「补充说明里写的是横线款，请再打开那份文件看看。」先确认读到了正确材料，再往下整理，比做出一整份清单后才追查来源要省事。

最后回到电脑里的两份原备忘，关闭先前查看它们的窗口，再从「材料」中重新打开，确认仍是原来的内容。我们还没有要求生成清单，此时不需要出现「结果」文件夹。两份文件找到了，具体内容也能对应，就留在这个聊天里，接着读下一章。

## 没得到预期结果时

| 停在了哪里 | 可以先做什么 |
|---|---|
| 下载后找不到文件 | 回到浏览器下载列表，使用显示文件位置的入口；若下载没有完成，先等它完成 |
| 解压后文件夹层级对不上 | 找到里面直接有「材料」的「我的待办」，不要只按最外层文件夹的名字判断 |
| 双击备忘打开了别的软件 | 在文件上点右键，通过「打开方式」选择记事本或文本编辑 |
| 备忘打开后是乱码 | 先关闭，不要覆盖保存；使用支持UTF-8的文本打开方式。UTF-8是一种保存多种文字的编码方式，不确定设置时保留原件再处理 |
| 快捷键没有打开选择窗口 | 先确认当前使用Codex入口，并检查是否改过快捷键；官方命令名称为Open folder |
| Codex找不到两份备忘 | 核对连接的是「我的待办」，请它列出看到的文件名；已经建立的项目可在Edit project（编辑项目）中通过Add folder（添加文件夹）核对连接 |
| Windows提示尚未完成初始设置 | 先按应用引导完成首次环境设置，再回来打开文件夹；具体页面按第2章的安装路径核对 |
| 只是查看，关闭时却询问是否保存 | 先取消关闭，看看是否不小心改了文字；若确认不需要保留这些改动，再关闭而不保存 |
