# Codex完全零基础入门

一本面向没有编程基础读者的 Codex 入门书，桌面端为主，包含 CLI 的必要基础。

当前处于研究准备阶段。目录、产品基线和正文尚未确定；下面的三个单元是用于结构检查的占位，并非正式目录。

## 读者承诺

从日常任务出发，在需要时解释概念。关注怎样开始、怎样提供材料、怎样判断结果和处理问题，不设置练习题或作业要求。

详见[作品需求摘要](需求文档.md)。本书拥有独立的 Git 仓库，与系列其他作品分开维护。
